# PREMSNAPS — Free Website

This is a responsive one-page wedding photography website.

## Files
- index.html — page content
- style.css — design
- script.js — small interactions

## Before publishing
1. Replace `hello@premsnaps.in` in index.html if your preferred email is different.
2. Replace the Unsplash image URLs with your own wedding/pre-wedding photos for a fully branded portfolio.
3. Add your WhatsApp number to a CTA if desired.

## Free hosting option
GitHub Pages supports custom domains on GitHub Free public repositories. After uploading these files to a public repository, enable Pages and set the custom domain to `premsnaps.in`.

For the domain DNS, GitHub currently documents these A records for the apex domain:
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153

For `www`, use a CNAME pointing to `YOUR-GITHUB-USERNAME.github.io`.

Do not delete or alter Google Workspace MX/TXT records when connecting the website.
